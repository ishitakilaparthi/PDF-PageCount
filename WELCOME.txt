💡 PRO TIPS
════════════════════════════════════════════════════════════════════════════

1. FASTEST SETUP
   Windows: Double-click start.bat
   Mac/Linux: ./start.sh

2. GENERATE SAMPLE PDFs
   python create_sample_pdfs.py

3. PORT CONFLICTS
   If ports 3000/5000 are busy:
   Windows: netstat -ano | findstr :5000
   Mac/Linux: lsof -i :5000

4. CUSTOMIZE COLORS
   Edit: frontend/tailwind.config.js
   Update: primary & secondary colors

5. INCREASE FILE LIMITS
   Edit: backend/server.js
   Search: fileSize limit (default 50MB)

📞 QUICK HELP
════════════════════════════════════════════════════════════════════════════

PROBLEM                          SOLUTION
─────────────────────────────    ───────────────────────────
Port 5000/3000 already in use   Kill process (see GETTINGSTARTED.md)
npm install fails               npm cache clean --force
PDF won't upload                Verify it's a valid PDF < 50MB
CORS error                      Check both servers running
Excel export fails              Check disk space & permissions
UI doesn't refresh              Clear browser cache (Ctrl+Shift+R)
